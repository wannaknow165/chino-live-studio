# CHINO chat-flow verification — 2026-11-10

## Scope and evidence

Owner-authorized synthetic inbound chat/opponent turns were sent to the existing core on port 7780. Real GPT decisions and the existing headless stage decoder produced actual playback acknowledgements. This was not public TikTok chat delivery, human-microphone capture or physical-speaker verification. The configured TikTok account was offline. No new video was generated by these rehearsals.

The full 17-case sequence covered a room opening, solo chat without the wake name, Hebrew slang, identity, English wellbeing, compound questions, fresh viewers, battle invitations, natural-language private operator commands, battle addressing, same-viewer follow-ups, opponent follow-ups, listening requests, unknown scores and chat progress while media is missing. Natural-language solo/battle mode commands were actually applied and the original mode restored.

## Findings and deployed fixes

- A request to let a speaker finish proposed an unnecessary spoken acknowledgment. Added semantic `turn_yield` with a grounded wait/listen cue and a second review for unsupported classifications. A negated stop command does not become a request for silence.
- A mislabeled invitation was silenced by that new category; the counterexample was retained and the grounding/recheck added. No successful full-LIVE claim was made.
- Global 90-second repetition protection blocked a new participant's valid invitation. Cooldown now follows the recipient; same-recipient and anonymous-room repetition protection remains.
- The lone ready English wellbeing clip was incorrectly used as a game acceptance. Added a relevance rejection and second bank review. That original run's optimistic `passed` value was corrected with an audit record preserving the actual wrong decision and playback evidence.
- Explicitly active LIVE hosting can initiate a room turn immediately with a ready stage, continue short room initiatives during chat loss, and use a 12-second initiative interval with a minimum 3.5-second post-output gap. Speech, mute, effects, queued replies and dialogue controls still take priority. Disconnected practice does not start an imaginary room. This scheduling behavior has deterministic code tests, not public-broadcast evidence.
